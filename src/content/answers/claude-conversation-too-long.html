Claude says the conversation is too long: the fixes that work

Short answer: the chat has filled Claude's context window. On a paid plan, turn on code execution in Settings, then Capabilities, and Claude summarises earlier messages automatically instead of stopping. Otherwise, ask for a handover summary before the limit and continue in a new chat.

The message means Claude can no longer read the whole conversation at once. Every new message sends the chat back to the model, and a long one, full of files and pasted code, eventually outgrows the window. These are the fixes people trade in Claude communities, checked against Anthropic's own documentation.

The fixes, most effective first

  1. Turn on automatic context management. On paid plans with code execution enabled, Claude summarises earlier messages to make room and keeps the full history so it can still refer to it. Anthropic says this lets conversations continue indefinitely in most cases. Switch on Code execution and file creation under Settings, then Capabilities; on Team and Enterprise plans an owner controls it. The trade-off: long chats that trigger it use more of your usage limit.
  2. Ask for a handover before the wall. The most common workaround. Ask Claude to summarise the goal, the decisions and the open questions, then paste that into a new chat. Do it while answers are still sharp: at the limit there may be no room left to write the summary. A handover format that works.
  3. Keep a running checkpoint. A variation shared in Claude communities: every so often, ask Claude to update a short notes file of what has been decided. When a chat ends, the next one starts from that file, and several new chats can start from the same one.
  4. Move reference material into a Project. Projects use retrieval: Claude loads only the relevant parts of project files into the context window, so documents you reuse do not fill every chat.
  5. Split a huge first message. Anthropic notes that a very large first message can still hit the limit. Send only the part you need, or put the document in a Project.

What does not help

  • Waiting for a reset. This limit is the length of the chat, not your usage allowance. A new five-hour session does not shorten the conversation. Claude's usage limits are a separate limit.
  • Pasting the whole transcript into a new chat. It fills the new window with the same problem.
